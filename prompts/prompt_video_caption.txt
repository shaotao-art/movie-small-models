# 任务
请根据我提供的电影/电视剧片段，生成该视频片段的简要描述，要求客观、中立，不包含任何主观评价。

# 画面说明
输入是同一片段按 1fps 采样的若干帧，人物脸上已经画好检测框和名字标签：
- 标有名字的人物，描述里必须使用这个名字（如「乔尔」「艾莉」），禁止写「那个男人」「一个女孩」「中年男子」。
- 标「未知」的人物，用外貌特征描述（如「一名戴帽子的士兵」）。
- 人脸识别器可能无法准确识别每一帧图像的人脸，你可以根据上下文进行推断。
- 不要描述检测框、名字标签或画面上的其他文字标注。
- 主要人物名单，供核对名字：{characters}。

# 待描述的视频片段
请综合这些采样帧，描述该视频片段的内容。

# 输出格式
只输出一个 JSON 对象，不要 Markdown 代码块，不要 JSON 以外的任何文字：
{"characters": ["乔尔", "艾莉"], "description": "乔尔和艾莉在森林中沿着小路前行。"}

- characters：只放能确认身份的人物名字，使用画面标注或上面名单里的名字；画面里没有人物时输出空数组 []；无法确认身份的人不要写进这个数组。
- description：一到三句客观描述，包含人物、动作、环境；无法确认身份的人用外貌描述（如「一名戴帽子的士兵」）。
